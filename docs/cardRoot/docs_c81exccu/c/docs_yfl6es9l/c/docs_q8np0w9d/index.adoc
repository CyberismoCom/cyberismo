The MCP server runs as part of the Cyberismo backend. Start it with:

[source,bash]
----
cyberismo app
----

The MCP endpoint is then available at `http://localhost:3000/mcp`. To use a different port:

[source,bash]
----
PORT=4000 cyberismo app
----

== Claude Code

Add the following to `~/.claude/claude_desktop_config.json`:

[source,json]
----
{
  "mcpServers": {
    "cyberismo": {
      "type": "http",
      "url": "http://localhost:3000/mcp"
    }
  }
}
----

Restart Claude Code after saving. Ensure `cyberismo app` is running before starting Claude Code.

=== Installing the skill discovery bootstrap

Because skills are enabled dynamically, an AI assistant must be told to ask for them. The following command installs a bootstrap skill that does this and also writes the MCP server configuration:

[source,bash]
----
cyberismo install-skills
----

Run the command in the directory that your AI assistant operates in -- usually the root of your repository -- or give that directory as an argument. The command writes the following files:

* `.claude/skills/dynamic-skill-discovery/SKILL.md` -- the bootstrap skill, with instructions for looking up the enabled skills before acting on a task
* `.mcp.json` -- the `cyberismo` MCP server entry; entries for other MCP servers are left unchanged
* `CLAUDE.md` -- a short pointer to the bootstrap skill, inside a block that Cyberismo manages

Use the `--target` option to choose the AI assistant platform (`claude` is currently the only supported platform and the default), and the `--url` option to register an MCP server URL other than the default `http://localhost:3000/mcp`:

[source,bash]
----
cyberismo install-skills --target claude --url http://localhost:4000/mcp
----

The command is safe to run again: it replaces only the Cyberismo-managed block in `CLAUDE.md` and the `cyberismo` entry in `.mcp.json`. It also overwrites `.claude/skills/dynamic-skill-discovery/SKILL.md`, so any local edits to that file are lost.

To write your own skills, see {{#xref}}"cardKey":"docs_qd5gotpx"{{/xref}}.

== VS Code

Add the following to `.vscode/mcp.json` in your project:

[source,json]
----
{
  "servers": {
    "cyberismo": {
      "type": "http",
      "url": "http://localhost:3000/mcp"
    }
  }
}
----

Reload VS Code after saving. Copilot Chat will then have access to Cyberismo tools.

== stdio mode (alternative)

If the HTTP server is not available, the MCP server can run as a subprocess communicating over stdin/stdout.

*Claude Code* — add to `~/.claude/claude_desktop_config.json`:

[source,json]
----
{
  "mcpServers": {
    "cyberismo": {
      "command": "cyberismo",
      "args": ["mcp", "--project-path=/path/to/your/project"]
    }
  }
}
----

*VS Code* — add to `.vscode/mcp.json`:

[source,json]
----
{
  "servers": {
    "cyberismo": {
      "command": "cyberismo",
      "args": ["mcp", "--project-path=${workspaceFolder}"]
    }
  }
}
----

== Troubleshooting

*Tools not appearing* — restart Claude Code or VS Code after configuration changes and verify the backend is running.

*HTTP endpoint not responding* — check that port 3000 is not in use by another process and that the URL in your config matches the running server.

*stdio server not starting* — ensure `cyberismo` is installed and in your PATH, and that the project path contains a `.cards` directory. Run `cyberismo mcp` manually to see error output.
