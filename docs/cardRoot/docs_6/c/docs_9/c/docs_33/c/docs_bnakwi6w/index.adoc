== Parameters

* `Key`: An identifier of an object. For example, a card key.
* `Field`: A name of a field
* `Value`: The value of the field
* `DataType`: The data type of the field. See {{#xref}}"cardKey":"docs_25"{{/xref}} for more information

== Description

The `field` predicate with 4 parameters is the output atom of the query language. For each scalar attribute of a query result, the query language shows a `field(Key, Field, Value, DataType)` atom, which the query result parser turns into a property of the result object.

Queries do not write this predicate. To give a result an attribute, select a field, or construct the attribute with {{#xref}}"cardKey":"docs_g9t7ad0x"{{/xref}} or {{#xref}}"cardKey":"docs_h1sm98ea"{{/xref}}. A `field` head in a query is a violation of the rule that queries never write predicates that the main logic program reads.

The data type determines the JSON type of the property: `number` and `integer` become JSON numbers, `boolean` becomes a JSON boolean, and `stringList` becomes an array. `shortText`, `longText`, `person`, `date` and `dateTime` become strings, and `enum` and `list` become objects and arrays. Any other data type is not output: the attribute is dropped.
